# Field Studio — design system

This Storybook is the **living contract** for every component on the site. If it is not here, it
does not exist.

- **Tokens** — `tokens/tokens.json` → CSS variables. Never use raw colours; use `bg-background`,
  `text-muted-foreground`, `bg-signal`… Toggle dark / light in the toolbar.
- **UI** — shadcn/ui primitives (`src/components/ui`). Copy new ones from shadcn, never hand-roll.
- **Sections** — page building blocks composed from UI.
- **Works** — generative installations. Use the controls on *Works / GenerativeWork* to explore
  `seed`, `density`, `palette` and brand colours.

## What every story is tested for

1. `play` interactions (clicks, keyboard, focus)
2. Accessibility (axe, WCAG 2.2 AA) — violations fail CI
3. Layout — no horizontal overflow, no overlapping controls, no clipped text
